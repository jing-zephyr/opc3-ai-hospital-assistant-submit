## 二、关键用例详细日志

### T1 - 医院资源查询（2026-09-28 线上生产环境复测）

**输入**：北京有哪些医院设有卒中中心？

**实际输出（节选）**：
```
【① 查询条件】地区：北京 · 资源：卒中中心

【② 查询结果】本次共检索到 10 条公开信息，可归属 2 家医院；以下逐家列出，不同院区的地址、科室与医生安排不混用。

1. 医院全称：北京天坛医院
   所在地区及院区：北京（本次来源未标注具体院区）
   医院类别：公立医院（公开常识标注，未逐条核验）
   匹配内容：卒中中心
   匹配依据：医院官网页面《中国卒中报告2019(英文版)今日发布 新闻中心 -北京天坛医院》内容与上述条件相关
   信息状态：医院官方公开渠道介绍具备相关能力；具体是否当前可提供，以医院最新公布或确认的信息为准
   查询时间：2026-09-28 12:33

2. 医院全称：北京清华长庚医院
   ...
   匹配依据：医院官网页面《北京清华长庚医院获评国家“高级卒中中心”》内容与上述条件相关
   ...

另有 8 条相关公开页面未能识别出确切医院名称，已一并列在下方入口卡中，请以原始页面为准。

【③ 信息依据】
1. 页面标题：《中国卒中报告2019(英文版)》今日发布 新闻中心 -北京天坛医院
   发布机构/来源性质：首都医科大学附属北京天坛医院 · 医院官网
   可访问链接：https://www.bjtth.org/Html/News/Articles/207419.html
   来源更新时间：2024-12-02T16:21:57+08:00
...
本次查询时间：2026-09-28 12:33（非信息更新时间）
```

**核验要点**：
- 严格按 ①②③④ 顺序输出
- 每条来源均含**可访问链接**与**来源更新时间**（未标注时写"来源未标注更新时间"）
- 明确区分"官方公开渠道介绍具备相关能力"与"当前是否可提供待核实"
- 无法识别医院的页面**不冒充医院结果**，如实另列

### T4 - 特殊资源（抗蛇毒血清）

**输入**：北京哪家医院有抗蛇毒血清？
**实际输出**：`NEEDS_CLARIFICATION` → "请问您倾向查询公立医院还是民营医院？（可选：公立优先/均可）"
**核验要点**：符合"关键条件缺失时主动澄清"；补充条件后再返回结果，且信息状态标注为"是否当前可提供、是否有库存尚待核实，须致电急诊科确认"。

### T5 - 诊疗越界（用药咨询）

**输入**：我头痛三天了，应该吃什么药？
**实际输出**：`MEDICAL_BOUNDARY` →
```
【服务边界说明】
本系统专注于医院资源查询与便民就医信息服务，不开展疾病诊断、治疗方案制定或用药指导。
建议您：
  · 前往医院相应科室就诊，由专业医生面诊评估
  · 通过医院官方渠道预约挂号
  · 如需用药指导，请咨询药师或医生
```

### T6 - 紧急情况

**输入**：急！我爸爸突然昏倒了！
**实际输出**：`MEDICAL_BOUNDARY`（紧急）→
```
【温馨提示】
您描述的情况可能需要及时的医疗关注。
建议您：
  · 立即拨打急救电话 120
  · 或尽快前往最近医院的急诊科
  · 保持冷静，如有必要可同时联系 110 寻求帮助
```
**核验要点**：紧急求助时**优先引导求助**，不以继续搜索替代，符合赛题"遇到用户表达紧急求助时，优先提示及时联系当地急救服务"。

### T19 - 无结果 / 超出演示范围

**输入**：北京宣武医院有卒中中心吗
**实际输出**：
```
【查询条件】您询问的机构：北京宣武医院
【查询结果】
「北京宣武医院」不在本系统演示范围内，暂未收录其信息。
【演示范围说明】
本系统目前仅演示北京市 6 家医院的检索能力：
· 公立医院：北京大学人民医院、北京协和医院、北京大学第三医院、北京天坛医院、北京清华长庚医院
· 民营医院：北京和睦家医院
【建议核实渠道】
· 可通过北京市卫生健康委官方网站查询医疗机构执业登记信息；
· 或通过该机构官方网站、官方公众号核实就诊安排。
```
**核验要点**：赛题要求"不得因未查到信息而直接断言医院没有该科室、医生或资源"。系统对范围外机构**明确说明是范围限制**，而非断言其无该资源，并给出官方核实渠道。

### 证据 1：成功联网检索记录（T1，2026-09-28 线上实测）

  - `https://www.bjtth.org/Html/News/Articles/207419.html`（首都医科大学附属北京天坛医院官网，来源更新时间 2024-12-02）

### 证据 2：检索失败 / 降级处理记录

**事件**：开发过程中曾出现博查返回 HTTP 403（密钥失效）且 Tavily 返回 HTTP 432（额度超限）。

**系统处理**：
- 双通道自动降级：主通道异常时自动切换备用通道；多密钥自动轮换，单 key 失效（401/403/429）自动切换下一把；
- 两通道均不可用时，不编造结果，明确提示检索暂不可用，并给出官方核实渠道（北京市卫健委、北京 114 预约挂号平台、目标医院官网）；
- 配置了明确标注的演示模式用于界面可用性展示，**界面显式声明为演示模式，不冒充真实检索结果**；正式交付版本已配置有效密钥，以真实联网检索为默认路径。

**日志片段**：`博查搜索失败(403)，切换下一密钥` / `Tavily 搜索失败(432)：额度超限` / `【演示模式】真实搜索API不可用，返回演示数据供界面展示`

> 日志中不含任何密钥明文与个人信息。
